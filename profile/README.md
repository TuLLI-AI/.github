# TüLLI-AI

**[Tübingen Language, Learning and Inference Group] — a research group at the University of Tübingen.**

We are interested in language models, particularly in how ideas from **logic, automated reasoning and probabilistic inference**
can help us understand, constrain and improve modern AI systems. 

This page collects the group's open-source code, research artifacts and
teaching materials.

## 🔬 Research code

| Repository | Description |
|---|---|
| [**symprog**](https://github.com/TuLLI-AI/symprog) | A small Python library for symbolic programming and tractable inference: write weighted Boolean formulas and discrete probabilistic programs, then count models, compute exact probabilities and take gradients. `pip install symprog` |
| [**Copper**](https://github.com/TuLLI-AI/Copper) | Code for *CoTs as Probabilistic Programs: A Programmatic View of Thinking Step-by-Step in Language Models* (NeurIPS 2026). |

## 📚 Teaching (Winter Semester 2026/27)

| Course | Description |
|---|---|
| [**Discrete Methods for Modern AI**](https://github.com/TuLLI-AI/DiscreteMethodsAI) | SAT solving, model counting, tractable inference and probabilistic programming, applied to language modeling and generative AI. |
| [**Introduction to Logic**](https://github.com/TuLLI-AI/IntroLogic) | Introductory class on discrete mathematics |
